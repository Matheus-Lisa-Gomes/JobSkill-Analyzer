Bloco 1 • Dias 1 a 30

Fundação Prática de Dados & Código

Garantir fluência na skill mais exigida do mercado (SQL 92%) e estruturar scripts de limpeza de dados em Python.

  • ✓ SQLbolt & DataLemur: Praticar diariamente Window Functions, CTEs e junções complexas.
  • ✓ Python Pandas: Scripts para limpar planilhas e ler dados CSV/JSON com tratamento de nulos.
  • ✓ Git & GitHub: Criar repositório público documentando os 30 dias de queries e scripts.
  • ✓ Candidaturas Imediatas: Disparar inscrições para estágios em Salvador (Hospital Aliança, Dasa, TRE, SEFAZ).
Bloco 2 • Dias 31 a 60

Integração de APIs, Automações & BI

Conectar o mundo dos dados com sistemas backend e automação low-code/pro-code com n8n e FastAPI.

  • ✓ FastAPI + PostgreSQL: Construir uma API REST com rotas GET/POST, Pydantic e banco local.
  • ✓ n8n + LLM APIs: Automação que recebe webhook, consulta API de IA para extrair dados em JSON e salva no banco.
  • ✓ Power BI & DAX: Criar dashboard com modelo estrela (Star Schema) consumindo a base tratada.
  • ✓ Decisão de Foco: Certificação Microsoft PL-300 (se Dados) ou aprofundamento em FastAPI/Docker (se Backend).
Bloco 3 • Dias 61 a 90

Projeto Flagship & Vagas Remotas em USD

Posicionar seu perfil para vagas internacionais remotas em Dólar e empresas multinacionais aproveitando o Inglês C1.

  • ✓ Docker Compose: Subir PostgreSQL e FastAPI em containers isolados com deploy no Render/Railway.
  • ✓ Projeto Flagship Integrado: Pipeline ponta a ponta na área de Saúde ou Logística com vídeo demo em inglês (Loom de 3 min).
  • ✓ LinkedIn em Inglês: Perfil otimizado para ATS com keywords extraídas deste analisador (SQL, Python, Power BI, FastAPI).
